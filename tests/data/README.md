# J613 2.0.1 reference results

`j613-201-golden.csv` was generated by compiling the unmodified
`Speaker::run_model` method from MIT speakersafetyd 2.0.1,
`63a92658a4daec170c6472e38162374206e593fb:src/types.rs` (The Asahi Linux
Contributors). Complete types.rs SHA256:
`0fcd8c23ac8edc9a2e8a8ee95e982c268177a4cc1be8bf8e843be4ad57a9b3dc`.
The local rollback source's types.rs was byte-identical to that public commit.

A value-only stub supplies the original fields; its debug macro is discarded.
No ALSA device is opened. Initialize coil/magnet to 125/90 C and their holds
to the same values. Set the original J613/J413 constants and derive min_gain
with the original 18.5 dBV/nominal-impedance formula. For each of the four
outputs, pass seven 4096-frame, 8-channel S16 periods at 48000 Hz, with both
its voltage and current word equal to 100, 500, 1000, 2000, 3000, 1000, then 0.
Other channels are zero. Output coil/magnet f64 bits and gain f32 bits after
each original `run_model` call. The checked-in test runs the new model on
those same inputs and checks all bits; it does not reimplement its equations.

Generated on native aarch64 Linux using rustc 1.93.1. Values are regression
and arithmetic-parity evidence, not a physical thermal/transfer certificate.
