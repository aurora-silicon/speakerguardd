# speakerguardd 0.1 (legacy)

This branch, `legacy/v0.1`, holds the original 0.1.x speakerguardd: the
feed-forward daemon for the MacBook Neo (J700) described in the README.
It is frozen. The tag `v0.1-final` marks the last commit of the line as it
stood on `main` before the switch.

The main line is now speakerguardd 2 (the `main` branch, formerly `v2`).
New features, new machines and tuning work go there.

This branch takes security and safety fixes only. To propose one, open a
pull request against `legacy/v0.1`. Anything else belongs on `main`.
